# 1. Record architecture decisions

Date: 2026-03-02

## Status

Accepted

## Context

We keep having the same design discussions, because nobody can find out why the code looks the way it does.

## Decision

We record each decision that is expensive to reverse as a short, numbered file in `docs/adr`. An accepted record is not edited: a new record supersedes it.

## Consequences

Decisions, including the options we rejected, can be read in the repository, and reviewed like code.
